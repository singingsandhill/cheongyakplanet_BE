API 개요


CheonYakPlanet provides a RESTful API for Korean real estate subscription management, along with WebSocket support for real-time AI chat.


Base URL: http://localhost:8080/api

Authentication: JWT Bearer Token

Content-Type: application/json



인증 (Authentication)


인증 흐름

  1. 회원가입: POST /api/member/signup
  2. 로그인: POST /api/member/login
  3. 토큰 사용: 헤더에 Authorization: Bearer {access_token} 포함
  4. 토큰 갱신: Access Token 만료 시 POST /api/member/auth/refresh
  5. 로그아웃: POST /api/member/logout

토큰 구조

  • Access Token: 유효기간 60분
  • Refresh Token: 유효기간 24시간
  • 저장 방식: 데이터베이스 저장 및 블랙리스트 지원


API 엔드포인트


사용자 관리 (/api/member) — UserController


회원가입 (Register User)
POST /api/member/signup
Content-Type: application/json

{
  "email": "user@cheonyakplanet.com",
  "password": "password123!",
  "username": "청약초보",
  "phoneNumber": "010-1234-5678"
}

로그인 (Login)
POST /api/member/login
Content-Type: application/json

{
  "email": "user@cheonyakplanet.com",
  "password": "password123!"
}

로그아웃 (Logout)
POST /api/member/logout
Authorization: Bearer {access_token}

카카오 OAuth 콜백 (Kakao OAuth Callback)
GET /api/member/kakao/callback?code={authorization_code}

카카오 토큰 교환 (Kakao Token Exchange)
GET /api/member/kakao/exchange?state={state}

토큰 갱신 (Refresh Token)
POST /api/member/auth/refresh?refreshToken={refreshToken}

마이페이지 조회 (Get My Page)
GET /api/member/mypage
Authorization: Bearer {access_token}

프로필 수정 (Update Profile)
PATCH /api/member/mypage
Authorization: Bearer {access_token}
Content-Type: application/json

{
  "username": "청약전문가",
  "marriageStatus": "기혼",
  "numberOfChildren": 2,
  "monthlyIncome": 600,
  "totalAssets": 2500,
  "hasHouse": false
}

응답에 갱신된 Authorization 헤더가 포함됩니다.


회원 탈퇴 (Delete Account / Withdraw)
DELETE /api/member/mypage
Authorization: Bearer {access_token}

아이디 찾기 (Find ID)
POST /api/member/find-id?email={email}

비밀번호 찾기 (Find Password)
POST /api/member/find-password?arg0={email}&arg1={username}

비밀번호 재설정 (Reset Password)
POST /api/member/reset-password?arg0={email}&arg1={username}&arg2={inputCode}&arg3={verificationCode}&arg4={newPassword}&arg5={confirmPassword}

관심 지역 추가 (Add Interest Location)
POST /api/member/location
Authorization: Bearer {access_token}
Content-Type: application/json

{
  "locations": ["서울특별시 강남구", "경기도 성남시"]
}

관심 지역 삭제 (Remove Interest Location)
DELETE /api/member/location?locations=서울특별시 강남구&locations=경기도 성남시
Authorization: Bearer {access_token}

WebSocket API


실시간 AI 채팅 (Real-time AI Chat)


연결 (Connection)
ws://localhost:8080/ws/chat

JWT 토큰은 JwtHandshakeInterceptor를 통해 핸드셰이크 시 검증됩니다.


const socket = new WebSocket(`ws://localhost:8080/ws/chat?token=${token}`);

메시지 형식 (Message Format)

텍스트 메시지를 직접 전송합니다 (JSON이 아닌 일반 텍스트):

강남구 청약 자격 조건이 궁금해요

서버는 Gemini 2.0을 통해 AI 생성 텍스트로 응답합니다.


사용 제한 (Usage Limits)
  • 일일 제한: 사용자당 15개 메시지 (매일 00:00 UTC에 초기화)
  • 동시 세션: 사용자당 1개 세션
  • 자동 요약: 5개 이상 메시지 후 대화 자동 요약


응답 형식 (Response Format)


성공 응답 (Success Response)

{
  "status": "success",
  "data": { ... }
}

오류 응답 (Error Response)

{
  "status": "fail",
  "data": {
    "code": "AUTH001",
    "message": "유효하지 않은 JWT 서명"
  }
}

전체 오류 코드 목록은 오류 코드 문서를 참고하세요.
